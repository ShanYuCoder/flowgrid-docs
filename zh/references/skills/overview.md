# Skill: `/overview`

## 名称 (Name)
`overview`

## 使用方式 (Command/Trigger)
- 调用 Slash 命令：`/overview`
- Executed during Phase 0 project setup.

## 输入 (Input)
- Product requirements document (PRD), business goals, target personas, technical boundaries.

## 输出 (Output)
- Master overview document: `overview/index.md`.
- High-level product vision, user personas, operational areas, and milestone roadmap.

## 描述说明 (Description)
- 在 Phase 0 梳理产品的核心业务目标、解决的用户痛点、用户角色分类 (Personas) 与版本里程碑范围。
## 相关技能 (Related Skills)
- **Followed by:** `/surfaces`, `/module`, `/user-flow`.

---

## 提示词调用示例 (Example Prompt)

```text
/overview

Draft master overview/index.md for a B2B SaaS logistics and fleet tracking platform, including target personas, core modules, and release milestones.
```
