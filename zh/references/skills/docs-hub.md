# Skill: `/docs-hub`

## 名称 (Name)
`docs-hub`

## 使用方式 (Command/Trigger)
- 调用 Slash 命令：`/docs-hub`
- Used to manage and render documentation hub portals.

## 输入 (Input)
- Documentation hub root directory.

## 输出 (Output)
- Rendered Markdown artifacts, VitePress build outputs, and navigation sidebars.

## 描述说明 (Description)
- 管理 VitePress 本地文档中心服务，汇总运行 `flowgrid docs`，启动本地多端文档预览与实时热更新。
---

## 提示词调用示例 (Example Prompt)

```text
/docs-hub render
```
