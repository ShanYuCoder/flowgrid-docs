# `/grill-api-unit`

**Description:** /grill-unit — BE grill gate before /unit API test generation.

## Overview
Audit gate that runs before committing backend unit tests generated by `/api-unit`. It verifies that the generated tests properly cover the endpoints defined in `01-backend-spec.yaml`.

## Target Resolution
1. Resolves `01-backend-spec.yaml` using the provided ID/slug and `FLOWGRID_DOCS_ROOT`.
2. Compares the generated test skeletons (from `api-unit-gen:dry`) against the spec file.

## Check Requirements
- Verifies that tests cover all defined endpoints.
- Ensures authentication and tenant fixtures use trusted context (not naive stubs).
- Checks distinct assertions for edge cases and errors.
- Validates async test idempotency.
