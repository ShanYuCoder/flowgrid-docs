# Skill: `/docs-hub`

## スキル名 (Name)
`docs-hub`

## 使用方法 (Command/Trigger)
- スラッシュコマンド実行：`/docs-hub`
- Used to manage and render documentation hub portals.

## 入力 (Input)
- Documentation hub root directory.

## 出力 (Output)
- Rendered Markdown artifacts, VitePress build outputs, and navigation sidebars.

## 説明・役割 (Description)
- VitePress ドキュメントハブの管理、`flowgrid docs` の統合実行、ローカルでの多言語ドキュメントプレビューとホットリロードを提供。
---

## プロンプト実行例 (Example Prompt)

```text
/docs-hub render
```
