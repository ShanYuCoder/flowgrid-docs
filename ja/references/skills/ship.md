# スキル: `/ship`

`/ship` — 品質監査ゲート、Gitプッシュ、PR作成＆納品更新。

## 🛡️ バイパス不可の品質監査ゲート

`/ship` はコードをリモートに送信する前に以下の自動監査を必須実行します:
- 仕様構造検証（`flowgrid:audit spec`）
- フロント・バック契約整合（`flowgrid:audit fe-be`）
- 自動テスト成功検証（`flowgrid:cases-check`）

## 🚢 出荷フロー

1. **品質検証:** クリティカルエラー時は出荷を直ちに中断。
2. **コミット:** 課題番号を紐づけたConventional Commitメッセージを生成。
3. **プッシュ:** リモートリポジトリへ安全に送信。
4. **プルリクエスト作成:** GitHub/Backlog/GitLab上で監査結果テーブル付きPRを発行。
5. **課題更新:** チケットを「レビュー中（In Review）」に更新し、PRリンクを自動投稿。

## 🚀 使用方法

```text
/ship                        # 監査、コミット、プッシュ、PR作成を一括実行
```
