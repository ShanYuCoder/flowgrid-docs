# Skill: `/docs-mark`

## Name
`docs-mark`

## Usage (Command/Trigger)
- Call via slash command: `/docs-mark <action> <target>`
- Used to stamp or audit documentation lifecycle marks across the workspace.

## Input
- Target documentation files (specs, architectures, user flows).

## Output
- Updated frontmatter metadata or lifecycle badges on documentation artifacts.

## Description
- Manages documentation verification status, review stamps, and sign-off indicators.
- Synchronizes documentation lifecycle states with quality gate audits.

---

## Example Prompt

```text
/docs-mark verify surfaces/admin/CMP-ADM-ORD/01/01/order-list.bundle.yaml
```
